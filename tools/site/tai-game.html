Tải game miễn phí

Cài một lần là xong – mỗi lần game cập nhật, ứng dụng trên máy tính và điện thoại tự có nội dung mới, nút tải cũng luôn là bản mới nhất.

Máy tính Windows

Windows 10 / 11 · 64-bit

Tải cho Windows
  1. Giải nén file .zip, mở HiepSiNetChi-win_x64.exe (cần mạng, mỗi lần mở là bản game mới nhất).
  2. Nếu Windows báo "đã bảo vệ máy tính": bấm Thông tin thêm → Vẫn chạy.

Điện thoại Android

Android 7 trở lên · tự có nội dung mới

Tải cho Android
  1. Mở file HiepSiNetChi.apk vừa tải.
  2. Nếu máy hỏi, cho phép "Cài ứng dụng không rõ nguồn" rồi bấm Cài đặt.
